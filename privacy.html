Privacy

Last updated 20 October 2026.

4 U By U turns a YouTube lecture into study notes. It runs entirely in your browser, and it has no server of its own. This page says exactly what it reads, what it keeps, and the one thing it sends anywhere.

The short version

The captions of the lecture you choose are sent to the AI provider whose API key you supplied — Groq, at api.groq.com — so that it can write the notes you asked for. That is the only request that leaves your browser. There is no account, no analytics, no advertising, no tracking, and no server that we operate or could read from.

If you would rather not send anything to a third party, do not press Generate. Reading the page, choosing a model and seeing the estimate send nothing.

What it reads

  • The page you are on, only on https://www.youtube.com/*: the video's title, channel, id, duration, and the caption track the player already loaded.
  • The captions of that lecture, which is how the notes are written.
  • Nothing else on the page, and no other site. It cannot read other tabs or other sites.

What leaves your browser

WhatWhereWhy
Your API key https://api.groq.com, in the request's own authentication header It identifies your account to the provider. It is not sent anywhere else.
The caption text and title of the lecture you asked about, in the prompt The same address It is what the model reads to write the notes.

That request is made from the extension's own background worker, not from the YouTube page, so the page's security policy cannot see or change it. The provider's handling of what it receives is governed by Groq's privacy policy, not by this one.

What it keeps, and where

Everything it keeps stays in your browser's own storage for the extension (or your script manager's storage, for the userscript version). None of it is synced to any account, and none of it is readable by anyone else.

  • Your API key — so you do not have to paste it again on the next lecture.
  • Your chosen model — so the estimate and the run use the model you picked.
  • The notes you generated, kept in “My notes” — so a finished lecture can be reopened or downloaded again without paying for it twice.
  • A usage ledger — tokens the provider reported, per model, per day, kept on your machine so the panel can warn you before a run would exceed the day's allowance. It contains no text from the lecture.
  • In-progress work — a part that was written before an interruption, so a run can continue instead of starting over.

You can delete the key in the panel, and everything else by removing the extension or clearing the extension's site data. Uninstalling it removes its storage with it.

What it never does

Creates an account, or asks for your name, email or anything personal Never
Loads analytics, telemetry, advertising, or a third-party script or font Never
Reads your browsing history, your other tabs, or any site other than YouTube Never
Downloads or runs code from the internet Never
Sells, rents or shares data with anyone, or uses it for advertising or profiling Never
Sends the lecture's captions anywhere except the provider you configured, and only when you press Generate Never

The notes you download

The notes are one self-contained HTML file saved by your browser, wherever your browser saves downloads. It contains the lecture's title, channel, timestamps, the notes, and links back to YouTube at each timestamp. It has no scripts that contact a server, no fonts or styles from the internet, and no analytics: it opens from your own disk, offline, for as long as you keep it. Sharing it shares exactly what is written in it, nothing more.

Children

It is not directed at children under 13, and it collects nothing about anyone. A child using it would still need an API key of their own, which requires accepting the provider's terms.

Changes

If what the program sends or stores ever changes, this page changes with it in the same commit, and the date at the top changes. The source is public, so the claims here can be checked against the code.
